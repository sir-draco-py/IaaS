# 📡 Rangkuman Jaringan Nirkabel & Teknologi Wireless

> **Panduan Belajar Interaktif** — Rangkuman lengkap mata pelajaran Jaringan Nirkabel mencakup Modul 1, 2, dan 3 dalam format website interaktif berbasis HTML murni.

---

## 📖 Tentang Project

Website ini adalah rangkuman belajar interaktif untuk mata pelajaran **Jaringan Nirkabel & Teknologi Wireless**. Dibuat sebagai media belajar mandiri yang menggantikan catatan konvensional dengan tampilan yang lebih visual, terstruktur, dan mudah dinavigasi.

Seluruh konten dikemas dalam **satu file HTML** tanpa dependensi eksternal selain Google Fonts — tidak perlu server, tidak perlu install apapun, cukup buka di browser.

---

## 🗂️ Struktur Konten

### 📡 Modul 1 — Dasar & Gelombang Radio
Membahas fondasi dasar jaringan nirkabel dan karakteristik gelombang.

| Tab | Isi |
|-----|-----|
| Jaringan Nirkabel | Pengertian, karakteristik, dan cara kerja dasar |
| Gelombang Radio | Sifat gelombang, propagasi, dan medium transmisi |
| Frekuensi & Panjang λ | Rumus, perhitungan, dan spektrum frekuensi |
| Modulasi Analog | AM, FM, PM — prinsip dan perbandingan |
| Modulasi Digital | ASK, FSK, PSK, QAM |
| Rangkuman & Tips | 10 poin kunci + tips ujian Modul 1 |

### 📶 Modul 2 — Jenis Teknologi Nirkabel
Membahas klasifikasi jaringan nirkabel dan teknologi generasi selular.

| Tab | Isi |
|-----|-----|
| WPAN | Wireless Personal Area Network, Bluetooth, IEEE 802.15 |
| WLAN | Wireless Local Area Network, Access Point, IEEE 802.11 |
| WWAN | Wireless Wide Area Network, sel heksagonal |
| Generasi Selular | 1G, 2G (GSM/GPRS/EDGE), 3G, 3.5G (HSDPA) |
| FDMA / TDMA / CDMA | Teknik multiple access dan perbandingannya |
| Rangkuman & Tips | 10 poin kunci + tips ujian Modul 2 |

### 🔌 Modul 3 — Karakteristik Perangkat Jaringan Nirkabel
Membahas perangkat keras, standar IEEE, bentuk jaringan, dan channel.

| Tab | Isi |
|-----|-----|
| Perangkat Nirkabel | WAP, Router, Antena Yagi/Grid/Parabolic/Omni |
| Standarisasi IEEE | 802.11a/b/g/n — perbandingan spesifikasi |
| Bentuk Jaringan | Ad-Hoc vs Infrastruktur, kelebihan dan kekurangan |
| Nirkabel Channel | Tabel channel 2,4 GHz, channel non-overlapping |
| Rangkuman & Tips | 10 poin kunci + tips ujian Modul 3 |

## ✨ Fitur Website

- **Navigasi Modul** — Beralih antar Modul 1, 2, dan 3 dengan satu klik
- **Navigasi Tab** — Setiap modul punya tab topik tersendiri
- **Kartu Informasi** — Materi disajikan dalam card grid yang mudah dibaca
- **Tabel Perbandingan** — Data teknis disajikan dalam tabel yang bersih
- **Pro-Con Grid** — Perbandingan kelebihan dan kekurangan secara visual
- **Highlight Box** — Kotak khusus untuk rumus, tips, dan poin penting
- **Rangkuman Ujian** — Setiap modul punya halaman ringkasan 10 poin kunci
- **Responsive** — Dapat dibuka di desktop maupun mobile

## 🚀 Cara Pakai

Tidak perlu instalasi apapun. Cukup:

1. Download file `index.html`
2. Buka dengan browser (Chrome, Firefox, Edge, Safari)
3. Navigasi menggunakan tombol Modul dan Tab

> ✅ Bisa dibuka secara offline tanpa koneksi internet (font akan fallback ke system font)
